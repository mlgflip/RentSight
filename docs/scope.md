# PropOS — Model Scope

**What the model predicts (verbatim for the write-up):**

> Given a residential property's square footage, bedrooms, bathrooms, age, lot size, location (zip code and distance to coastline), this model predicts its expected monthly rent in Key Biscayne and greater Miami-Dade County zip codes, in current US dollars.

**Explicitly out of scope:** home valuation (sale price prediction), short-term/vacation rental rates, commercial property, markets outside Miami-Dade County.

**Why one target:** two models (valuation + rent) doubles the work without doubling the credibility. Rent prediction is the single narrow target.
